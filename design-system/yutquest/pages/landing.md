# Yutquest landing page overrides

This page refines the generated Yutquest master system for an older learner and culture-curious audience.

## Direction

- Pattern: editorial storytelling + interactive product demonstration + feature-rich showcase.
- Tone: warm, clever, culturally considered, tactile, and modern.
- Avoid: childlike classroom styling, generic gamification, glossy 3D, neon gradients, ornamental motion, and invented social proof.

## Color

- Paper: `#F5F0E7`
- Deep paper: `#E9DFCF`
- Ink: `#18211D`
- Forest: `#173C36`
- Lacquer red: `#C84B3D`
- Muted gold: `#D6A54D`
- Blue ink: `#2B5265`

Use red for emphasis and cultural warmth, gold for rewards and Yut outcomes, and forest green for immersive game surfaces. Maintain WCAG AA contrast for all working text and controls.

## Typography

- Interface and body: local Geist variable sans-serif.
- Display: Georgia / system editorial serif with Korean serif fallback.
- Body minimum: 16px on small screens with 1.6–1.8 line height.

## Interaction

- Real interactions over decorative spectacle: playable Yut throw, selectable learning-loop tabs, revealable idiom cards.
- Micro-interactions: 150–300ms; longer object movement may run up to 500ms.
- Animate transform and opacity only, preserve keyboard operation, show visible focus, and respect reduced motion.

## Layout

- 1240px maximum editorial canvas with mobile-first reflow.
- Check 375px, 768px, 1024px, and 1440px.
- Use asymmetry on wide screens but maintain a single clear reading order on small screens.
